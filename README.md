# SettleUp

## Graph & Tree-Based Group Expense Settlement Engine

SettleUp is a full-stack application for managing shared group
expenses and calculating an optimized set of transactions required
to settle outstanding balances.

### Core DSA

- HashMap
- Tree
- DFS
- Max Heap
- Greedy Algorithm

### Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Jest
